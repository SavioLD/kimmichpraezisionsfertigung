# assets/

Hier gehören die echten Medien der Website hin.

Aktuell offen (Platzhalter im Code sind mit der CSS-Klasse `.ph` markiert):

- **Echte Fotos** – Bearbeitungszentrum, 5-Achs-Fräsmaschine, Automation, Frästeile,
  Werkstatt/Team. Ersetze die `<div class="ph">…</div>`-Blöcke in den HTML-Seiten durch
  `<img>`-Elemente.
- **Echtes Logo** – ersetzt aktuell die Buchstaben-Marke (`.brand__mark`) sowie ggf.
  `favicon.svg`.

## Vorhandene Dateien
- `favicon.svg` – Platzhalter-Favicon (blaues „K").
